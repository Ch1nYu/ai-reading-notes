## 完整摘要

### 擴展法則與涌現特性
Altman 指出職業生涯中最有趣的現象皆與「擴展帶來的涌現特性」有關：無論是模型損失函數、聚集頂尖人才研究單一問題、Y Combinator 批次規模擴大產生的網路效應，都是在特定尺度才出現、小規模完全不存在的屬性。他承認無理論解釋，但經驗上「若某事物在小規模已運作良好，將其推向前所未有的大規模，多半是好主意」，且嚴重被低估。人類難以直覺理解指數增長，導致許多專家持續低估擴展潛力。

### ChatGPT 與 Codex 的產品發現歷程
ChatGPT 並非預先規劃產品：GPT-3 API 初期無商業進展，開發者卻大量用 API 金鑰進行對話；團隊遵循 YC 原則「看使用者熱愛什麼就做什麼」，以 GPT-3.5 快速推出聊天機器人，五天內流量呈現「漲跌反覆但峰值不斷創高」模式，確認擁有殺手級產品。Codex 原為核心策略（程式碼控制數位世界、機器人控制物理世界），因 ChatGPT 爆發而延後，直到近期（逐字稿稱「5.5」）才出現真正拐點。

### AI 研究管線將由 AI 重寫
當前管線為預訓練、中訓練、後訓練、RL 與監督回饋迴圈；Altman 明確預期會經歷「重大重寫」，並設定目標：2027 年 9 月前以 500,000 張 A100 等效 GPU 做 AI 研究實習生，2028 年 3 月前擁有完整端到端的優秀 AI 研究員，能設計全新架構。他認為現有管線與架構足以推過「AI 能做不可思議工作」的門檻。

### 智慧作為新公用事業與算力瓶頸
Altman 用電力普及歷史類比：電力公司不賣「電力」而賣「夜間照明」；OpenAI 也需找到「我們賣給你的是什麼」的敘事。消費者將以 token 或更高層級（如持續運行的代理服務）付費，底層晶片細節會被抽象化。他指出算力短缺極大（H100/Blackwell 長約與現貨價差 5 倍），且隨模型更聰明、成本更低，需求無上限，「只要持續進步，短缺將永遠存在」。

### 教育體系適應 AGI 嚴重滯後
Altman 承認預測錯誤：原以為 ChatGPT 推出後一年內教育系統會重新設計，但三年半來未見系統性變革。若繼續用前 AGI 方式教學評分，將導致批判性思維萎縮。部分技能（寫作、程式）仍值得教導以培養元認知，但大部分內容需徹底改變教學與評估方式。

### 未來十年兩大關鍵分叉：民主化 vs 集中、算力分配
第一分叉：技術是廣泛民主化（80% 機率）還是集中在少數公司？集中會造成極不穩定、對齊失敗、不公平；OpenAI 將盡力推動普及，但會面臨安全論點與權力集中勢力阻力。第二分叉：算力成為最重要公用事業，價格失衡時如何公平分配算力？他傾向「公民財富基金」讓人人擁有資本切片，而非固定現金 UBI，認為更符合人類心理。

### 給「單人前沿實驗室」專案的建議
Altman 認為前沿模型無論如何都會出現，真正投資不足的是「大規模交付廉價智慧」的推理層；建議學生轉向推理基礎設施，因所有前沿實驗室終將成為推理公司。

## 可參考資料
- **Y Combinator (YC)**：Altman 任職 YC 時觀察到批次擴大產生網路效應，並套用 YC「看使用者熱愛什麼」原則決定推出 ChatGPT。
- **OpenAI**：Altman 所領導公司，演講多次引用其內部決策歷程（GPT-3 API、GPT-4、ChatGPT、Codex、擴展模型、推理基礎設施目標）。
- **GPT-3 / GPT-3.5 / GPT-4**：演講中提到的模型版本演進節點，GPT-3 API 商業化失敗、GPT-3.5 用於 ChatGPT、GPT-4 當時已完成未發布。
- **Codex**：OpenAI 程式碼模型，原為核心策略，後因 ChatGPT 爆發延後，近期版本「5.5」出現能力拐點。
- **Nikolaj Dangen (Nicolai Tangen)**：挪威主權財富基金負責人，課程邀請講者，持有全球 1.5% 上市公司股份，實際運作類 UBI 機制，Altman 引用為所有權模式範例。
